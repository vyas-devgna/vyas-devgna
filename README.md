**An elegant, high-performance Flutter Android client for [same.energy](https://same.energy) — the AI-powered visual search engine.**

Built with Glassmorphism design, buttery-smooth animations, and thoughtfully designed architecture powered by Riverpod.

<details>
<summary><b>✨ Features & Architecture</b></summary>
<br/>

**🔍 Intelligent Search**
- Visual Search — Upload any image to find visually similar content
- Text Search — Natural-language queries with AI matching
- Hybrid Search — Combine image + text for laser-precise results

**🎨 Premium Design**
- Glassmorphism UI with translucent surfaces & blur effects
- Adaptive light & dark mode with system integration
- Fluid fade, slide, and scale transitions
- Pinterest-style masonry grid layout

**🏗️ Architecture**
- Clean Architecture with feature-first modules
- Riverpod for predictable reactive state management
- Dio networking with interceptors & retry logic
- GoRouter for declarative type-safe routing
- Encrypted token management & clickstream telemetry

</details>
